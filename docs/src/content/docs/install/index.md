このセクションには、engawaのインストール・運用時に使用する設定をまとめています。

## インストール手順

- [systemdでインストールする（Ubuntu / Debian）](/engawa/install/systemd-ubuntu/): Ubuntu 24.04・Debian 12を想定した、サーバー構築の全手順。
- [systemdでインストールする（RHEL系）](/engawa/install/systemd-rhel/): AlmaLinux・Rocky Linux・RHELを想定した、サーバー構築の全手順。

## 設定

- [バックエンドの環境変数](/engawa/install/environment-variables/): 設定ファイルとの優先順位、起動オプション、開発・テスト用の変数。
- [db.extra で指定できる設定](/engawa/install/db-extra/): PostgreSQL接続の細かい調整項目と、指定した値がどこに渡るか。
