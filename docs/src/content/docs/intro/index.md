engawaは、MisskeyのフォークであるCherryPickのフォークです。家の縁側のように、個人・少人数で気楽に運用できることを目指して開発しています。  

## 何でないのか
engawaはエンタープライズ向けのソフトウェアではありません。開発者は素人で、エンタープライズ用途に求められる強い耐障害性・安定性・より高度なセキュリティについていかなる保証もできません。開発者は現在1人です。何らかの理由で開発・更新が止まる可能性があります。フォークソフトウェアとは、往々にしてそのようなソフトウェアであることを留意して利用してください。  

engawaは、Mastodonではありません。Mastodon互換APIはありませんし、Mastodonのように高い信頼性などを保証できません。あくまで、個人・少人数で気楽に運用できることを目指しています。  

engawaは、MisskeyやCherryPickの派生ではありますが、どちらでもありません。
物議を醸す機能、開発者の思想に合わない機能は削除されることがありますし、逆に開発者の思想によって追加される機能もあります。

engawaは、yojo-artではありません。yojo-artは初期のengawaからの派生であり、開発者も初期には携わっていましたが、別のソフトウェアです。  

## 独自機能
CherryPickやMisskeyにはないという意味での独自機能のうち、代表的なものを列挙しています。これ以外にも、いくつかの仕様変更が含まれています。
- ブロックしたサーバーに投稿が流れないようにする機能 (Authorized Fetchモード)
- タイムラインからBotの投稿を除外する機能
- 自分の投稿を誰が検索できるかを投稿ごとに設定 (検索許可)
- ElasticSearch対応
- サーバーに登録されているアイコンデコレーションの一覧
- サーバーのステータスページを登録できるように

## 名前の由来
日本家屋の縁側からです。お寿司のエンガワではありません。縁側で日向ぼっこしながら猫を撫でる、そんな生活のように緩やかな過ごし方ができるソフトウェアを目指しているため、こんな名前がつけられました。
