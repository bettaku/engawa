---
title: What is engawa?
description: What engawa is, and where it is headed
---

engawa is a fork of CherryPick, which is itself a fork of Misskey. Like the engawa — the wooden porch of a Japanese house — it is built to be run comfortably by one person or a small group.

## What it is not
engawa is not enterprise software. Its developer is an amateur and can make no promises about the fault tolerance, stability, or hardened security that enterprise use demands. There is currently one developer. Development or updates may stop for any number of reasons. Please use it knowing that forked software often is this kind of software.

engawa is not Mastodon. There is no Mastodon-compatible API, and it cannot offer the level of reliability Mastodon does. It only aims to be something you can run comfortably, alone or with a few others.

engawa derives from Misskey and CherryPick, but it is neither of them. Features that invite controversy, or that do not fit the developer's thinking, may be removed; conversely, features may be added because of it.

engawa is not yojo-art. yojo-art branched from an early version of engawa, and this developer was involved in its early days, but it is separate software.

## Features of its own
Below are the notable features that Misskey and CherryPick do not have. There are also a number of other changes in behavior.
- Keeping posts from reaching blocked servers (Authorized Fetch mode)
- Excluding posts from bots in the timeline
- Per-post control over who may find it in search (search permission)
- ElasticSearch support
- A list of the avatar decorations registered on the server
- The ability to register a status page for the server

## Where the name comes from
It comes from the engawa, the porch of a Japanese house — not the cut of sushi. The goal is software that lets you pass the time as gently as sunbathing on the porch while petting a cat, which is how it got this name.
